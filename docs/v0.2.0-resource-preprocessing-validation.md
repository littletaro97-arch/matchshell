# MatchShell v0.2.0 资源预处理验证记录

## 本版本范围

- 首页只保留右上角一个圆点列表菜单，颜色使用项目品牌色 `#C2410C`。
- 菜单统一提供刷新、资源预处理、文件池和调试地址。
- 照片、视频压缩结果自动写入 `Downloads/火柴公益文件池`。
- 网页文件上传默认先进入原生文件池，可继续浏览其他文件。
- PPT、Word、ODP、ODT 进行输入容器能力探测，不输出伪 PDF。

## Office 转 PDF 能力验证结论

网站当前通过 Windows LibreOffice `soffice --headless --convert-to pdf` 生成 PDF。LibreOffice 官方源码包含 Android Viewer、LibreOfficeKit JNI 引导代码和 PDF 导出过滤器，说明从源码构建专用 Android 文档引擎在理论上存在路径；但官方 Android Viewer 不是可直接加入本工程的 Maven 转换库，当前 MatchShell 也没有可调用的 Android `soffice` 命令或稳定批处理 API。

本版本实际验证到的边界：

- PPTX/PPTM/PPSX、DOCX/DOCM：读取 ZIP 容器并检查主文档入口。
- ODP/ODT：读取 ZIP 容器并检查 `mimetype`。
- PPT/DOC：检查旧版 OLE Compound File 文件头。
- 文件只在本机读取，不上传服务器。
- 上述通过只代表输入容器可读，不代表排版、字体、动画、嵌入对象或 PDF 输出正确。

因此，本版本不把 PPT/Word 转 PDF 标记为已实现。下一阶段若继续走 LibreOfficeKit，需要单独建立 Android NDK/LibreOffice 交叉编译原型，并用真实 PPTX、DOCX、ODP、ODT 文件比较页面数、字体、图片、表格和导出 PDF；若 APK 体积、构建维护或兼容性不可接受，应停止该路线，而不是退化为伪 PDF。

## 待实机验证

- 右上角菜单在竖屏、横屏、刘海和手势区域的位置与可点击性。
- 照片和视频处理完成后是否出现在系统“下载/火柴公益文件池”。
- 网站上传按钮是否先展示文件池，选择照片或视频后是否成功回传给 WebView。
- “浏览其他文件”是否支持网站要求的单选、多选和 MIME 类型过滤。
- APP 重启后文件池索引是否仍能打开已有文件。
- 删除或移动系统中的池文件后，APP 是否自动清除失效索引。
