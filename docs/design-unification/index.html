所有颜色均已收敛到 colors.xml；新增 brand_10 用于图标背景与 meta pill 底色，避免各 drawable 中硬编码透明度。

本次修改内容

  • 资源预处理页：标题统一为 22sp 粗体；功能卡片统一 20dp 圆角、1dp 浅色描边、品牌色图标背景；按钮拆分为 Primary（品牌填充）与 Secondary（卡片底）两种样式；进度条与状态文案颜色统一。
  • 文件池：标题/空状态颜色 token 化；Grid 项增加卡片包裹（20dp 圆角）、缩略图加 12dp 圆角与描边；底部按钮使用 Primary 样式。
  • 主界面原生元素：右上角菜单按钮改为圆角卡片背景，与功能卡片风格一致；错误视图统一背景、文字颜色与 Primary 重试按钮。
  • 调试地址弹窗项：删除按钮不再使用系统红色，改为品牌色文字 + 品牌浅色 pill 背景，视觉统一。
  • 占位缩略图：文件池默认占位图颜色与 card 背景、brand 对齐。
