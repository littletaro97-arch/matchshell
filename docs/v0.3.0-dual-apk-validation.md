# MatchShell v0.3.0 双 APK 验证记录

## 产物契约

- Lite：`0.3.0-lite`，versionCode 30，applicationId `com.hcgy2018.site.lite`。
- PDF：`0.3.0-pdf`，versionCode 31，applicationId `com.hcgy2018.site.pdf`。
- 两者可以同时安装；各自维护应用内文件池索引，实际输出均位于公共 `Downloads/火柴公益文件池`。

## 共同功能

- 文件池使用相册式自适应网格。
- 图片、视频调用 Android MediaStore 缩略图；PDF 渲染首页；其他文件显示扩展名卡片。
- 点击文件用于选择/打开；长按弹出删除确认，同时删除 MediaStore 文件和索引。

## PDF 变体

- 只在 `pdf` source set 打包 `arm64-v8a/libzen_office2pdf.so`。
- 支持 DOCX、PPTX、XLSX，单文件最大 64 MiB。
- 转换结果必须以 `%PDF` 开头才写入文件池。
- 来源：ZenConverter commit `0b00f08e6dc170d85cd3f36163114217d4c27cd6` 的可复现 JNI 工程；上游 `office2pdf` 为 Apache-2.0，现成 JNI 构建来自 AGPL-3.0-or-later 项目。
- 原生库 SHA-256：`2B36E907B772514CF8B5840DE338DC21FFD6100B5E3E8F0487B6CD77B2958D5B`。
- 本机未安装 Android NDK，因此本轮使用已校验的上游 arm64 构建；对应 Cargo/JNI 源码与许可证保存在 `third_party/office2pdf/`。
- PDF APK 当前只用于本地能力验证；在独立重编 JNI 或完成 AGPL 分发合规前，不作为闭源正式发布包。
